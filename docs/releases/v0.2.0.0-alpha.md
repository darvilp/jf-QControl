# QControl 0.2.0.0 alpha

This release moves QControl to Jellyfin 12 and .NET 10. It uses the same plugin
GUID and protection behavior as the 10.11 line. Keep using version 0.1.0.1 on
Jellyfin 10.11; its catalog entry and download remain available.

## Compatibility

- Jellyfin packages 12.0.0, plugin ABI 12.0.0.0, .NET 10.
- Runtime smoke-tested on Jellyfin Server 12.0.0 and qBittorrent 5.2.3.
- One qBittorrent instance; qBittorrent 4.x is unsupported.

## Verification

The migration passed the Release build, 174 .NET tests, 18 dashboard tests,
package/release contracts, and CI. Disposable Docker tests verified plugin
installation and Active status, configuration persistence after restart,
administrator authorization, connection validation, and embedded resources.
API-reported playback activated Alternative Limits and torrent stops, then
restored the original state on stop. Explicit marked-torrent recovery passed.

## Installation and limitations

Use the existing QControl catalog URL. On Jellyfin 12 select 0.2.0.0 and restart.
Back up QControl configuration and resolve any recovery journal before changing
versions. Alpha configuration upgrades are not guaranteed; a clean QControl
configuration may be necessary. Configure and test the connection before
enabling actions.

Real-player/browser E2E, interruption/outage, temporary-manifest installation,
existing 10.11 configuration upgrades, native Windows runtime, and later 12.x
versions have not been validated for this release. Automatic crash restoration
remains intentionally disabled; recovery requires an administrator decision.
