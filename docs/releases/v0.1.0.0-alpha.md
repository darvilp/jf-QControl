# QControl 0.1.0.0 alpha

This is the first QControl alpha candidate. It reduces qBittorrent activity
while Jellyfin has playing or paused media sessions and restores only state it
can safely attribute to QControl.

## Compatibility

- Jellyfin Server `10.11.11` / plugin ABI `10.11.11.0`
- qBittorrent `5.2.3` / Web API `2.15.1`
- .NET `9.0`
- Containerized and native Linux Jellyfin are exercised; native Windows has a
  documented credential smoke procedure but is not yet runtime-verified.

## Included behavior

- Alternative Limits and Stop Torrents actions, independently selectable
- All-torrent or exact-category scope, including categorized and uncategorized
  torrents for the all scope
- Separate incomplete/completed torrent controls
- Configurable ownership Marker Tag and dominant Never-touch Tag
- Explicit-hash stop/start operations with queue-safe reconciliation
- Playing and paused session aggregation with configurable release grace
- Durable credential-free journal and conservative interruption recovery
- Administrator-only connection, configuration, status, and recovery APIs
- Responsive Jellyfin administrator page with write-only credentials

## Configuration and upgrade notes

New installations are inert. Configure one qBittorrent 5.2 API-key credential
source, pass the connection test, enable at least one action, and save before
QControl can mutate qBittorrent. See `docs/RELEASE.md` for manual installation,
secret-file permissions, interruption recovery, and removal guidance.

This is the first public-version candidate, so there is no previous package to
upgrade from. Upgrade-retention testing becomes required for the next version.

## Known limitations

- Only one qBittorrent instance is supported.
- qBittorrent 4.x is rejected.
- Automatic recovery after a Jellyfin/plugin process interruption is
  intentionally disabled; an administrator must choose an explicit recovery
  operation.
- Operator starts during active protection are stopped again unless the
  Never-touch Tag is added.
- VPN/public-IP validation and adaptive rate selection are not included.
- Native Windows Jellyfin credential behavior requires the documented manual
  alpha smoke.

## Verification

The candidate is covered by unit, HTTP contract, filesystem, package,
Jellyfin/qBittorrent container, administrator Chromium, interruption/outage,
temporary-manifest installation, and release-contract tests. The test network
uses generated trackerless torrents and an internal web seed only.
